Configure a integração com APIs de geração de vídeo

Chave de API

Insira sua chave da API do Google Gemini (Veo) para habilitar a geração real de vídeos. A chave é armazenada apenas localmente no seu navegador.

Se você possui um servidor backend para proteger sua API key, insira a URL aqui.

Informações

⚠️ Segurança

Para uso em produção, nunca exponha sua API key diretamente no navegador. Utilize um servidor backend como proxy para proteger suas credenciais.

🔗 Como obter uma API Key

  1. Acesse Google AI Studio
  2. Crie ou selecione um projeto
  3. Gere uma API key
  4. Certifique-se de que a API Generative AI está habilitada

🎬 Modelos Suportados

Veo 2 — Modelo de geração de vídeo do Google, acessível via Gemini API. Gera vídeos de alta qualidade a partir de prompts de texto.

🖥️ Backend Proxy (Recomendado)

Para proteger sua chave, configure um backend simples com Node.js:

// server.js (Node.js + Express)
const express = require('express');
const { GoogleGenAI } = require('@google/genai');

const app = express();
app.use(express.json());

const ai = new GoogleGenAI({
  apiKey: process.env.GEMINI_API_KEY
});

app.post('/api/generate', async (req, res) => {
  const { prompt, config } = req.body;
  try {
    const operation = await ai.models
      .generateVideos({
        model: 'veo-2.0-generate-001',
        prompt: prompt,
        config: config
      });
    // Poll for completion...
    let result = await operation;
    while (!result.done) {
      await new Promise(r => setTimeout(r, 5000));
      result = await operation;
    }
    // Return video
    const video = result.response
      .generatedVideos[0].video;
    res.json({ video: video.uri });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

app.listen(3000);
